# Current extracted evidence
Source: [pinned hardware-tested revision](https://github.com/amarkrasniqi54321-ctrl/wtwtwt/tree/54dca92055e7e58dbca2194c67b0cfc151e1ef20/meritve_2026-11-25). CSV timing summaries are calculated using receiver/host timestamps at millisecond precision, excluding nonconsecutive sequence pairs (one production reset). GPIO events are extracted from the ESP serial log. Pi run durations are application-local, not wall-clock boot-to-HALT. Raw logs remain in the linked fork. Projected wake CSVs are synthetic 144-hour scenarios, not measured events. See [current evaluation](../../docs/CURRENT_EVALUATION.md).
