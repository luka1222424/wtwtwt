# Final-profile derived evidence

Only BASELINE and dynamic HALT-enabled OPTIMIZED are in the current results. Source logs are pinned in [CURRENT_EVALUATION.md](../../docs/CURRENT_EVALUATION.md). Timing summaries use host/receiver timestamps at millisecond precision and consecutive sequences, excluding one reset. GPIO events are requests; Pi durations are application-local. SSH observations distinguish reachable from unreachable, not actual HALT duration. Projected wake events are synthetic, not measurements.
